# Callouts Reference

*Obsidian callout types for use as attention markers in workspaces.*

---

Callouts provide progressive depth within documents — a fast scan catches the signals, a deep read takes everything in.

Syntax: `> [!type] Title` / `> [!type]- Title` (collapsible, closed) / `> [!type]+ Title` (collapsible, open)

## Available types

| Type | Style | Usage |
|------|-------|-------|
| `[!note]` | Blue | Reflections, annotations |
| `[!abstract]` / `[!tldr]` | Blue-green | Summaries |
| `[!info]` | Blue | Contextual information |
| `[!tip]` / `[!important]` | Cyan-green | Key points |
| `[!success]` / `[!done]` | Green | Validations |
| `[!question]` / `[!help]` | Yellow-green | Open questions |
| `[!warning]` / `[!caution]` | Orange | Alerts |
| `[!failure]` / `[!missing]` | Red | Identified gaps |
| `[!danger]` / `[!error]` | Bright red | Critical errors |
| `[!example]` | Purple | Illustrations |
| `[!quote]` / `[!cite]` | Grey | Citations, references |

For recommended usage in Tekton projects, see [convention-callouts](convention-callouts.md).
