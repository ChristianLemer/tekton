# lexicon

Multilingual lexicon for Genesis.

Forged by the method's author for terms where literal translation would be inadequate, imprecise, or ambiguous. The agent consults this lexicon when creating a workspace in the user's language or when explaining a Genesis convention.

## Reference partition

This table is the reference for zone names in other languages. Take them from here — never translate a zone name word by word: a round trip through another language is how `Results in Abundance` once became `An Abundance of Results`.
