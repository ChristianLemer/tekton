# Gestures

*Nine gestures, one guardian.*

Each follows the Praxis anatomy (Tekton .. Praxis .. PRAXIS): name, intention, when, input, output, sequence, guardrails, source method.

---

## The nine gestures

| Gesture | Trigger | One-line |
|---------|---------|----------|
| [CAPTURE](CAPTURE.md) | "I have a task." | Add a task to the backlog without friction |
| [GROOM](GROOM.md) | "Let's do a grooming." | Walk the backlog to produce clarity |
| [ALLOCATE](ALLOCATE.md) | "What should I do?" | Plan a period respecting balance and inflections |
| [CALIBRATE](CALIBRATE.md) | "Something has changed." | Adjust the balance to context |
| [COMPLETE](COMPLETE.md) | "It's done." | Signal what is done and trace it |
| [LET-GO](LET-GO.md) | "This is no longer relevant." | Consciously abandon a task |
| [REVIEW](REVIEW.md) | "How is my balance?" | Measure the gap between target and reality |
| [INTROSPECT](INTROSPECT.md) | "Help me understand." | Understand the patterns behind lingering tasks |
| [WEEKLY-REVIEW](WEEKLY-REVIEW.md) | "Let's close the week." | Close the period, re-decide each undone item |

## Breathing

| Moment | Gestures |
|--------|----------|
| Morning | Allocate |
| During the day | Capture, Complete |
| End of week | Weekly Review |
| When something changes | Calibrate |
| Periodically | Review, Groom, Introspect, Let go |

The system breathes at the human's rhythm, not the other way around.
