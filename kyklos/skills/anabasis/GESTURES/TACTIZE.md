# TACTIZE

Define recurring practices that implement strategy.

**When:** Strategy is established and needs to be translated into repeatable patterns.

**Input:** Strategy in `3a. Strategy/`.

**Output:** Tactics in `3b. Tactics/`.

**Sequence:**
1. Prospect: what tools, libraries, frameworks, or established practices support this strategy? What already exists that we can adopt?
2. Reread Strategy — what orientations need recurring support?
3. For each orientation: what habitual response implements it — leveraging what was found in step 1?
4. Write the tactics — concrete, repeatable moves.
5. Check: does each tactic trace back to a strategic orientation? Orphan tactics are waste.

**Guardrails:** Tactics are habitual responses — patterns you apply without re-deciding each time. If a pattern requires fresh judgment each time, it is not yet a tactic. If a tactic stops working, challenge the strategy (bridge) before inventing a new tactic.

**Source method:** Kyklos (production refinement module).
