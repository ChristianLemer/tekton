# DISTILL

Frame understanding for action.

**When:** The Picture is solid enough to act on — or the current Position has drifted from the Picture.

**Input:** Picture in `2. Picture/`.

**Output:** Updated Position in `3. Position/`.

**Sequence:**
1. What does the Picture reveal?
2. What stance does it call for?
3. What do we choose — and what do we accept as trade-off?
4. If Angles exist — take an explicit stance on each relevant angle.
5. Write the Position — using the template below when it is informed by Angles.
6. Review directives — do existing FRAME, CONSTRAINTS, CHOICES, CONSIDERATIONS, CONVICTIONS, TEMPERED still hold?

**Guardrails:** Position is prescriptive. If you find yourself describing rather than choosing, you are still in Picture territory. A Position that doesn't close any doors is not a Position. Position is situated: fragments hold views under conditions; Position recognises which conditions are ours and decides. In Organon, it is informed by Angles — it takes an explicit stance on each relevant angle and accepts the trade-off.

**Position template (when informed by Angles):**

```
# [Name]

## Source angles

- **[angle]** : we choose [pole] rather than [other pole] — [why]

## Motto

**"[short phrase]"**

## Position

[What we decide. Prescriptive.]

## Why

[What this position makes possible.]
```

**Source method:** Kyklos (common trunk).
