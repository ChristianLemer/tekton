# Gestures

Organon gestures. Each follows the Praxis anatomy (Tekton .. Praxis .. PRAXIS).

---

## Trunk Gestures (shared with Elasis and Anabasis)

| Gesture | Transition | One-line |
|---------|-----------|----------|
| [OBSERVE](OBSERVE.md) | 0 → Fragments | Draw from an experience a view on one aspect |
| [CONSOLIDATE](CONSOLIDATE.md) | Fragments → Sketch, then Angles → Picture | Reveal patterns (executed twice) |
| [DISTILL](DISTILL.md) | Picture → Position | Frame for action |
| [FORGE](FORGE.md) | Operational → Forge | Materialise |
| [ACCEPT](ACCEPT.md) | Forge → go/no-go | Confront with the previous deliverable and with the workshop |
| [DELIVER](DELIVER.md) | Forge → Deliverable | Advance the accepted state, tag it |
| [HARVEST](HARVEST.md) | (external) → Fragments | Import from another project |
